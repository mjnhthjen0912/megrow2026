# me.grow 2026 – Leadership Topics

Tài liệu song ngữ EN–VI cho 16 topic của chương trình me.grow 2026 (Zalo × RMIT University).

- Mở `index.html` (tự chuyển tới `Leadership Topics.dc.html`).
- Cần chạy qua web server (GitHub Pages, `npx serve`, `python3 -m http.server`); mở trực tiếp bằng `file://` sẽ không tải được các topic.
- GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
